# Privacy Policy

## Purpose

Personal Drive Connector is a private, owner-operated
integration that uses rclone to access the owner's Google
Drive files from the owner's private server.

## Google data access

The integration accesses file names, metadata, and file
contents as needed to list and read the selected Drive folder.
It is intended to use read-only access.

Google account authorization is completed through Google.
The integration does not request or store the owner's
Google password.

## Storage and use

OAuth credentials are stored in a restricted configuration
on the private server, separate from Drive files and this
website. File data and metadata may be cached locally
as needed for access.

Google user data is not sold, used for advertising, or
intentionally published through this website. Access is
for the owner's personal use.

## Revoking access and removing local data

The owner can revoke the integration's access through
their Google Account security settings. Revocation stops
future authorized access but does not itself delete
existing local copies or caches. Those must be removed
separately from the server.

## Website hosting

This informational website is hosted by GitHub Pages.
GitHub may process visitor connection information under
its own privacy policies. This website does not
intentionally include analytics or tracking scripts.
